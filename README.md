# Electric-Motor-Temperature-Prediction-Regression-Project-
Built a Python predictive regression pipeline estimating electric motor temperatures (stator, rotor, windings) from multi-sensor data. Handled EDA, preprocessing, and multicollinearity. Tuned Linear Regression, Random Forest, and XGBoost via GridSearchCV. Evaluated with $R^2$ and RMSE for real-time predictive maintenance. 
# ⚡ Electric Motor (PMSM) Permanent Magnet Temperature Prediction

## 1. Project Overview
Permanent Magnet Synchronous Motors (PMSMs) are widely deployed in electric vehicles, wind turbines, and industrial machinery. Monitoring the rotor's **permanent magnet tooth temperature (`pm`)** is critical to prevent demagnetization and thermal failure, but placing physical sensors directly on a rotating shaft is costly and impractical. 

This project builds a machine learning pipeline trained on **1.33 million sensor records** from `Regression.db` (`electric_motor_temperature` table) to accurately estimate `pm` using stator voltages, currents, motor speed, coolant, and ambient temperatures.

---

## 2. Features Selected & Domain Engineering
To ensure identical data processing during both model training and inference (`preprocess.py`), the following raw and engineered features were selected:

### Raw Sensor Features:
* `u_q`, `u_d`: $q$ and $d$ components of stator voltage (Volts)
* `i_q`, `i_d`: $q$ and $d$ components of stator current (Amps)
* `motor_speed`: Rotational speed of the motor
* `coolant`: Motor coolant outlet temperature (°C)
* `ambient`: Ambient temperature close to the stator (°C)

### Engineered Physics Features:
1. **`voltage_magnitude`** ($\sqrt{u_d^2 + u_q^2}$): Total stator voltage vector magnitude.
2. **`current_magnitude`** ($\sqrt{i_d^2 + i_q^2}$): Total stator current magnitude, representing copper/Joule heating losses ($I^2R$).
3. **`apparent_power`** ($u_d i_d + u_q i_q$): Total electrical active power input into the motor.
4. **`thermal_diff_coolant_ambient`** ($\text{coolant} - \text{ambient}$): Captures baseline heat dissipation efficiency.
5. **`speed_current_ratio`**: Distinguishes high-speed cruise regimes from high-torque stall regimes.

*(Note: `profile_id` was used strictly for `GroupShuffleSplit` validation so that driving cycles do not leak across train and test sets, and was excluded as a predictive feature so the model generalizes to unseen sessions.)*

---

## 3. ML Model Selected
**Selected Model:** **LightGBM Regressor (`LGBMRegressor`)**

### Justification:
* **Scalability on 1.33M Rows:** Histogram-based gradient boosting processes 1.33 million records in seconds with low RAM consumption compared to standard Random Forests or SVMs.
* **Non-Linear Thermal Dynamics:** Effectively captures complex interactions between electrical load, rotational speed, and thermal dissipation.

---

## 4. Feature Importance
*(Note: Update the exact numbers below from the console output after running `python train.py` on your machine)*

 typically ranks features in the following order of importance:
1. **`coolant`** – Baseline thermal state of the cooling system strongly anchors the rotor temperature.
2. **`ambient`** – Environmental heat sink baseline.
3. **`motor_speed`** – Influences both iron core eddy losses and convective air cooling inside the air gap.
4. **`thermal_diff_coolant_ambient`** – Heat transfer differential.
5. **`voltage_magnitude` & `u_q`** – Reflects back-EMF, which varies with magnet temperature and speed.
6. **`current_magnitude` & `apparent_power`** – Captures heat generated by electrical load.

## 5. Evaluation of Model
The dataset was split 80/20 using `GroupShuffleSplit` grouped by `profile_id`.
* **Root Mean Squared Error (RMSE):** `2.8196°C`
* **Mean Absolute Error (MAE):** `1.4498°C`
* **R² Score:** `0.9800`
